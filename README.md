# AstrBot 角色小衣柜（预测试版）

为 AstrBot 人格保存服装名称、描述、参考图、风格和当前穿搭。同一人格跨授权窗口共享，不同角色隔离。适合希望手工管理角色衣柜并参与测试的 AstrBot 使用者。

本版本基于 ff6e8e07bc2da0833752932e4095848d96a52bff。已有 AstrBot 4.27.3 实例启动成功反馈；真实 QQ 消息、图片和模型工具链尚未完成验收，不是稳定版或全功能验收版本。

## 安装

在你自己的 AstrBot 实例插件管理中，通过仓库地址安装：

https://github.com/MisakaZhu/astrbot_plugin_character_wardrobe

仓库根包含 main.py、metadata.yaml、_conf_schema.json、requirements.txt 和 wardrobe/。依赖为 aiosqlite>=0.20,<0.23、Pillow>=12.3.0,<14，须与实例环境兼容。安装后核对插件加载状态，由宿主管理员在目标人格会话执行 `/衣柜 初始化`。完整命令见 [COMMANDS.md](COMMANDS.md)。

## 能力边界

- 支持手工添加、查看、编辑、删除服装，管理穿搭、风格及访问权限。
- 图片会经过校验与重编码；服装参考图不是角色换装生成图。
- AI 自主添衣和选穿在正式入口缺少可信调用 ID 时拒绝写入；保存 on 开关不代表能力可用。
- 自动衣柜上下文投影已关闭。模型提供方不限，但不承诺任何模型链已验证。
- 默认可信本地媒体根列表为空，仅信任插件自身数据目录。
- 完整资产备份恢复尚未验收，迁移前自动备份只覆盖数据库。

## 给安装 Agent 的提示词

复制以下内容给你自己的 Agent，并明确授权目标实例；这不是无条件一键成功的保证。

```text
请在我明确授权的 AstrBot 实例安装 https://github.com/MisakaZhu/astrbot_plugin_character_wardrobe 。先确认目标实例、版本、依赖及已有安装，备份插件代码、配置和完整数据。只安装本插件；已有目录不得盲覆盖或清空，保留可回滚副本。默认不改其他插件、共享依赖、网络域名或服务配置，不重启整个服务；必要扩大操作先说明影响并征得我确认。不索取或输出密钥，不使用他人的实例、账号或数据，不发送真实群聊，也不默认启用 AI 自主写入。安装后核对加载状态，提供初始化、列表、添加、穿、当前命令和所需权限，说明回滚方式。有阻碍就停止并报告，不绕过限制。本插件为预测试版，真实 QQ、图片和模型链未验收。
```

## 停用、卸载与回滚

先确认插件完成停用、没有在途写入，再备份完整数据根。数据目录由宿主 StarTools.get_data_dir 派生，数据库、图片资产和持久 namespace 应一起保留。卸载前确认是否删除数据。回滚需保留旧代码及对应配置、数据备份；不可假定新版数据库可直接交给旧版使用。完整恢复应先在独立环境验证。
